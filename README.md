## Contexto e objetivo

O Cidade Acessível é uma plataforma colaborativa para registrar barreiras de acessibilidade em espaços de uso coletivo e acompanhar as ações de melhoria, da identificação do problema até a verificação do resultado.

[PREENCHER: 2 ou 3 parágrafos com o problema que o grupo quer resolver]

### O que o projeto não é

A plataforma organiza relatos, evidências e ações. Ela **não** emite certificações oficiais, não realiza perícias e não garante que um local seja acessível para todas as pessoas. Avaliações técnicas e intervenções físicas dependem dos responsáveis competentes.
